# Basic Ideal Flow of PD

1. Design
2. Scripts
3. PnR
4. Reports

experienced PD engineers are constantly thinking:

"What's the earliest stage I need to change to fix this problem, while disturbing as little of the existing implementation as possible?

So the basic thing a junior physical design engineer would do is have an output reproducible. 
 
It can be achieve writing the tcl scripts. There would be a base scripts for flow, till the stage of sign off, we improve the scripts until it produce a printable output.

GUI is for: visualization, debugging, exploration
once we found out something that fix the issues, we add implementation in the script

TCL is for: implementation, automation, reproducibility. 

So the reproducibility refers to the implementation process is repeatable.
